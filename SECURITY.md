# Security Policy

Do not report vulnerabilities in public issues. Use GitHub Security Advisories
for the affected source boundary:

- [ApiMind Web, Skills, documentation, and integration](https://github.com/xfzen/apimind/security/advisories/new)
- [ApiMind Server](https://github.com/xfzen/apimind-server/security/advisories/new)

Include the affected component and version, reproduction steps, impact, and any suggested mitigation. Do not include production credentials or personal data.
