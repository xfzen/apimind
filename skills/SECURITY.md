# Security Policy

## Supported Version

Security fixes are made on the current `dev` branch. No published compatibility guarantee exists for older snapshots.

## Reporting

Report vulnerabilities privately through the repository's GitHub Security Advisory interface. Do not include credentials, customer data, or exploitable details in a public issue.

This repository must never contain live ApiMind MCP tokens or private project bindings. Use placeholders in examples and revoke any credential that is committed accidentally.
