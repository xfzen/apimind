# 生态与商业边界

[English](ecosystem.en.md)

独立客户端可以开源或闭源、免费或收费。单独销售客户端本身不会自动触发 Server 商业授权；是否需要商业权利取决于 Server 的实际使用方式。

个人非商业持续自托管可按 Server 的 BUSL Additional Use Grant 免费使用。组织评估、开发、测试、内部 CI 和 PoC 可免费使用。任何组织的生产使用，包括非营利和学术生产，均需要商业权利，除非获得单独审核的例外。

下列场景需要商业 Server 授权：

- 企业或其他组织生产部署；
- 捆绑、客户交付或私有化项目；
- Managed Hosting 或 SaaS；
- OEM、嵌入或白标；
- 基于 Server 向第三方提供收费能力。

最终边界以 [Server LICENSING](https://github.com/xfzen/apimind-server/blob/dev/LICENSING.md) 和签署的商业合同为准。
