# Roadmap

[中文](roadmap.md)

These are directions, not current capabilities, and carry no delivery dates:

- TCP, WebSocket, MQTT, and gRPC;
- generalized Proxy, Scenario, E2E, replay, and External Handler;
- SDK generation and Arazzo;
- OpenAPI 3.1/3.2;
- public/internal/admin route separation;
- PostgreSQL storage.

Use the [capability matrix](capabilities.en.md) and component documentation for current capabilities.
